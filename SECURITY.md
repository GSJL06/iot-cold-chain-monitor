# Política de Seguridad

## Versiones soportadas

Este proyecto se encuentra en desarrollo activo. Únicamente la rama principal (`main`) recibe soporte y actualizaciones de seguridad.

| Versión / Rama | Soportada |
|---|---|
| `main` | :white_check_mark: Sí |
| Versiones anteriores / otras ramas | :x: No |

## Reporte de vulnerabilidades

Si identificas una vulnerabilidad o problema de seguridad potencial en este proyecto, te solicitamos que lo reportes de forma privada y responsable:

1. Dirígete a la pestaña **Security** del repositorio en GitHub.
2. En la sección lateral izquierda, selecciona **Advisories**.
3. Haz clic en el botón **Report a vulnerability** para abrir un reporte privado.
4. Incluye todos los detalles posibles: descripción del problema, pasos detallados para reproducirlo, vectores de ataque potenciales y sugerencias de remediación si las tienes.

Por favor **no reportes vulnerabilidades a través de issues públicos**.

### Tiempo de respuesta

- **Tiempo de respuesta objetivo:** 7 días para confirmar la recepción del reporte y realizar la evaluación inicial.
- Si se confirma la vulnerabilidad, se coordinará la publicación del parche directamente en la rama `main`.

## Aviso sobre los datos

Este proyecto es de carácter demostrativo y educativo (portafolio). Todos los datos, métricas de telemetría, identificadores de dispositivos y configuraciones son **100 % sintéticos**. El repositorio no contiene información confidencial, código propietario ni datos reales de empleadores, empresas o clientes.
